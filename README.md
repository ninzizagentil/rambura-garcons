# Rambura Garçons — School Management System (Frontend)

React + Vite + Tailwind CSS v4 frontend, built in 5 phases per the project spec.

## Status

Phases 1–4 complete. Phase 5 (integration/persistence/responsiveness/testing) in progress.

## Run locally

```bash
npm install
npm --prefix backend install
npm run seed
npm run dev:backend
npm run dev
npm run build
